# Show DeepSeek Models in the Picker

After setting your API key, the DeepSeek models appear in the Copilot Chat model picker:

- **DeepSeek V4.1 Flash** — current public Flash model, 1M context, native image input, strong agent performance, and lower pricing.
- **DeepSeek V4-Pro** — current Pro endpoint, 1M context, best for users who still want the published Pro model id.

Legacy ids `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` are retired by DeepSeek and temporarily routed to `deepseek-flash` for compatibility.

If the models are hidden, open the Language Models manager and make sure the **DeepSeek** vendor is enabled.

[Open Language Models](command:workbench.action.chat.manage)
